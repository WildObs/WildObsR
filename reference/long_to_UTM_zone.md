# Convert Longitude to UTM Zone

This simple function takes a vector of longitude values and returns the
corresponding UTM zone(s) for the coordinates.

## Usage

``` r
long_to_UTM_zone(long)
```

## Arguments

- long:

  A numeric vector containing longitude values.

## Value

The function prints out the relevant UTM zones based off the longitudes
provided.
